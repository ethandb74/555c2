# 555c2
A LED chaser which blinks 10 LEDS in a variable speed sequence. This pcb has a space theme with the leds tracing out the Big Dipper, my personal favorite constilation. I also included some hand drawn PCB art. This Project was done to develop PCB and Schematic skills.
